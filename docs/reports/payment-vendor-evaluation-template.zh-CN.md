# 支付平台商务与接入评估模板

> 更新日期：2026-04-20  
> 适用对象：在筛选聚合支付、官方支付、国际 PSP、MoR 或跨境收款方案时，需要统一比较 `费率`、`账期`、`开通门槛`、`适合主体` 的产品、运营、财务、法务和技术团队。  
> 使用原则：这是一份可直接复制复用的模板，不是固定答案。真实费率、账期、冻结金、拒付成本、地区准入和行业限制高度依赖你的主体、行业、月交易额、目标国家和风控评估结果，必须以商户经理正式报价和合同条款为准。

## 1. 使用方法

建议按下面顺序使用这份模板：

1. 先列出候选平台
2. 先做 `准入过滤`，再做 `价格比较`
3. 不要只看名义费率，要一起看 `账期`、`拒付成本`、`冻结/保证金`、`技术改造成本`
4. 对中国大陆、本地钱包、跨境卡支付、SaaS 订阅、平台分账分别打分
5. 最后形成 `主方案 + 备选方案 + 兜底方案`

### 7.1 这 8 个问题一定要问

1. 中国大陆主体能不能直接开  
2. 香港主体和美国主体政策是否不同  
3. 预充值余额、钱包余额、点数充值是否允许  
4. 是否允许销售第三方服务或 API credits  
5. 是否允许 B2B 企业收款  
6. 是否支持平台型业务、帮商户收款分账  
7. 是否要求真实线上商品、订阅条款、退款政策页面  
8. 被风控或补件后多久恢复

## 13. 最后提醒

- `费率最低` 不等于 `综合成本最低`
- `能开通` 不等于 `适合长期主链路`
- `能支付` 不等于 `适合充值、订阅、分账或钱包余额业务`
- 最终一定要同时拿到：`报价`、`账期说明`、`类目说明`、`回调文档`、`合同样本`
