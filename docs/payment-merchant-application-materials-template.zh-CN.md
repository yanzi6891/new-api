# `new-api` 支付商户申请材料准备清单模板

更新时间：2026-04-19

## 1. 这份文档怎么用

这份文档不是讲代码，而是帮你在申请支付宝 / 微信支付商户能力前，把材料一次性准备齐。

最推荐的用法是：

1. 先复制这份清单到你自己的项目文档或企业网盘
2. 按“已准备 / 未准备 / 备注”逐项勾选
3. 缺什么补什么
4. 材料齐了再去申请，避免反复打回

适用场景：

- `new-api` 做站内充值
- PC 页面展示二维码
- 支付宝扫码支付
- 微信 `Native` 扫码支付
- 单商户、自营、直连接入

## 2. 先确定申请目标

### 2.1 本项目建议申请什么

结合当前项目，建议目标写成：

- 支付宝：当面付 / 扫码支付
- 微信支付：普通商户模式 + `Native` 支付
- 业务类型：站内余额充值 / API 额度充值
- 收款主体：你自己的企业或个体工商户

### 2.2 申请前先确认的 5 件事

- 是否使用企业或个体工商户主体
- 是否已经有公网域名
- 是否已经部署 HTTPS
- 是否网站内容已基本完整
- 是否能解释“充值后用户得到什么”

如果这 5 件事还没准备好，不建议马上提交申请。

## 3. 主体基础资料清单

### 3.1 通用主体信息

建议准备：

- 主体全称
- 统一社会信用代码
- 主体类型
- 法定代表人 / 经营者姓名
- 法人 / 经营者身份证号
- 注册地址
- 实际经营地址
- 联系手机号
- 联系邮箱

```md

- 主体名称：
- 主体类型：企业 / 个体工商户 / 其他
- 统一社会信用代码：
- 法定代表人 / 经营者：
- 身份证号：
- 注册地址：
- 实际经营地址：
- 联系手机：

```

### 3.2 证照材料

至少建议准备：

- 营业执照彩色照片或扫描件
- 法人 / 经营者身份证正面
- 法人 / 经营者身份证反面

补充说明：

- 微信支付 PC 网站接入指引明确列出了营业执照、身份证、银行账户等资料要求
- 企业如未完成三证合一，可能还涉及组织机构代码证等补充材料

建议整理模板：


## 4. 银行结算资料清单

### 4.1 必备资料

建议准备：

- 开户银行名称
- 开户支行名称
- 银行账户名
- 银行账号
- 开户行省市

不同主体常见情况：

- 企业：通常准备对公账户
- 个体工商户：有些场景可用对公账户，也有些场景支持经营者对私账户，最终以平台申请页为准

建议整理模板：

```md
- 开户支行：
- 开户名：
- 银行账号：
```

## 5. 网站与业务资料清单

这一部分是最容易被忽略，但最容易影响审核结果的部分。

### 5.1 网站基础信息

建议准备：

- 网站名称
- 网站域名

- 登录 / 注册页截图
- 用户中心 / 钱包页截图
- 联系我们 / 关于我们页面截图

可直接整理成：

```md

- 网站域名：
- ICP 备案号：
```

### 5.2 业务说明材料

支付平台审核时，经常最关心的是：

- 你卖的是什么
- 用户付费后得到什么
- 是否涉及违规、灰产、虚拟套利、代充代付
- 退款规则是什么

建议你提前写一份 100 到 300 字的业务说明，直接可复制到申请表里。

可参考模板：

```text
本平台为 AI 接口与模型调用服务平台，用户注册后可购买站内充值额度，用于调用平台内提供的模型与相关 API 服务。充值成功后，系统会自动向用户账户增加对应余额/额度。平台不提供线下实物交易，不涉及赌博、彩票、数字货币兑换、套现或其他违法违规业务。
```

### 5.3 商品 / 服务说明

建议准备：

- 充值档位说明
- 计费方式说明
- 是否支持退款
- 退款条件说明
- 联系客服方式

建议模板：

```md
## 业务说明

- 核心业务：
- 用户付费后获得：
- 充值档位：
- 计费方式：
- 是否支持退款：
- 退款规则：
- 客服联系方式：
- 备注：
```

## 7. 支付宝申请专用材料清单

### 7.1 支付宝侧重点

对本项目，支付宝申请时最重要的是两条：

- 商户主体已完成实名认证 / 升级认证
- 你的站点或应用信息足够完整，能说明业务内容

### 7.2 支付宝建议预先准备

- 支付宝商家账号

- 应用图标
- 应用简介
- 网站域名
- 网站页面截图

## 9. 你内部最好再补的 3 份说明

除了平台申请资料，建议你自己内部还准备这 3 份说明：

### 9.1 充值产品说明

写清楚：

- 充值后用户得到什么
- 充值额度是否永久有效
- 是否可转让
- 是否可提现

### 9.2 售后规则说明

写清楚：

- 什么情况可退款
- 什么情况不可退款
- 误充值怎么处理
- 到账异常怎么处理

### 9.3 风险说明

写清楚：

- 不支持提现吗
- 不支持线下转账提现吗
- 不支持代付代充提现吗
- 是否限制异常账户提现吗
