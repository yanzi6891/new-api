# 国外平台详细分场景选型表

更新时间：2026-04-20

> 说明：这份文档不是重新做一轮全网调研，而是基于当前这条会话里之前已经出现过的推荐逻辑，把当时提到的几款国外/国际支付平台重新按场景拆开整理。  
> 重点平台包括：`Stripe`、`Paddle`、`Adyen`、`Checkout.com`、`Airwallex`、`dLocal`，并补充 `PayPal / Braintree` 作为辅助支付方式视角。

## 1. 先说结论

如果把之前会话里关于国外平台的推荐压缩成最短版本，大致是这样：

- 如果你做的是 **出海 SaaS / API 平台 / 海外开发者产品**，主推荐通常是 `Stripe`
- 如果你做的是 **SaaS 订阅 / 数字产品 / 软件出海**，并且想少管一部分税务和法定销售责任，主推荐通常是 `Paddle`
- 如果你做的是 **中大型全球企业 / 全渠道品牌 / 多国家统一收单**，更值得重点看 `Adyen`
- 如果你做的是 **中大型国际线上支付业务 / 跨境电商**，`Checkout.com` 是很强的备选
- 如果你更看重 **多币种账户、跨境资金流、换汇、全球资金管理**，`Airwallex` 更值得看
- 如果你重点市场在 **拉美、中东、非洲等新兴市场**，`dLocal` 很重要
- 如果你面向 **欧美消费者**，并且很在意钱包支付转化，应该考虑补 `PayPal / Braintree`

也就是说：

> 这几家平台不是谁“绝对最好”，而是各自最适合不同业务结构。

## 3. 六个主平台逐个拆开看

## 3.1 `Stripe`

### 当时为什么会重点推荐它

在之前会话里，`Stripe` 基本被当成国际支付方向的默认主推荐之一，原因非常明确：

- 文档成熟
- API 体验强
- Checkout 现成能力成熟
- Webhook 体系成熟
- Billing 适合订阅
- Connect 适合平台分账
- 很适合开发者和产品团队快速上线

### 更适合什么业务

- 出海 SaaS
- API 平台
- 海外开发者产品
- 数字产品
- 海外充值
- 国际信用卡支付
- 订阅

### 强项

- 开发效率高
- 文档和生态完整
- 产品线覆盖支付、订阅、平台收款
- 对工程团队最友好

### 局限

- 并不是所有主体地区都同样容易开通
- 对某些超大型企业级线下/全渠道场景，不一定比 `Adyen` 更合适
- 对某些新兴市场本地方法覆盖，不一定比 `dLocal` 更强

### 在之前会话里的定位

如果你的国际链路只能先选一个主平台，之前会话里最常被放在第一位的通常就是：

- `Stripe`

---

## 3.2 `Paddle`

### 当时为什么会重点推荐它

`Paddle` 在之前会话里很重要，因为它不只是普通 PSP，而更偏：

- `MoR`（Merchant of Record）

也就是说，它的价值不只是“收款”，还包括：

- 托管一部分税务
- 托管一部分法定销售责任
- 托管一部分全球订阅复杂度

### 更适合什么业务

- SaaS
- 软件订阅
- 数字产品
- 面向全球销售的软件服务

### 强项

- 更适合不想自己扛全球税务与法定主体责任的团队
- 对订阅类业务尤其友好
- 能明显降低某些出海合规复杂度

### 局限

- 它不是单纯“更高级的支付网关”
- 控制权通常不如自己直接用 `Stripe`
- 结账流程、品牌控制、利润空间方面通常没那么自由

### 在之前会话里的定位

如果你当时的重点问题是：

- “我做的是软件订阅 / 出海 SaaS / 数字产品，能不能少管一点税务和销售主体责任？”

那当时 `Paddle` 是被放得非常靠前的。

---

## 3.3 `Adyen`

### 当时为什么会推荐它

`Adyen` 在之前会话里的定位一直比较清楚：

- 企业级
- 多国家
- 多渠道
- 全球收单
- 统一线上线下

### 更适合什么业务

- 中大型跨国企业
- 全球品牌
- 全渠道零售
- 平台型国际企业

### 强项

- 企业级稳定性强
- 全球收单能力强
- 线上线下一体化能力强
- 对复杂支付架构支持更完整

### 局限

- 通常更偏中大型客户
- 商务和接入流程相对更重
- 对中小团队来说，上手成本通常高于 `Stripe`

### 在之前会话里的定位

它不是“默认人人先上”的平台，而是：

- 当你的规模和复杂度上来后，很值得认真评估的平台

---

## 3.4 `Checkout.com`

### 当时为什么会推荐它

它在之前会话里的角色，是国际线上支付方向的强备选。

### 更适合什么业务

- 跨境电商
- 中大型线上支付
- 国际线上收款

### 强项

- 国际线上支付能力比较均衡
- API 化程度高
- 在中大型线上业务里很常作为 `Stripe` / `Adyen` 的对比项

### 局限

- 对普通中小团队来说，品牌心智不如 `Stripe` 强
- 自助化和生态广度通常不如 `Stripe`
- 也不像 `Paddle` 那样直接解决税务合规托管问题

### 在之前会话里的定位

如果你的重点是：

- 国际线上业务
- 中大型交易规模
- 想认真做多家 PSP 对比

那它通常属于必看的强备选。

---

## 3.5 `Airwallex`

### 当时为什么会推荐它

因为它不是只做“收款”视角，而是更偏：

- 跨境支付
- 多币种账户
- 换汇
- 全球资金流管理

### 更适合什么业务

- 跨境卖家
- 出海品牌
- 多币种收款和结算
- 对资金管理有较强要求的团队

### 强项

- 资金流管理能力突出
- 多币种和财务协同价值高
- 对跨境团队的综合价值往往不只是支付

### 局限

- 它的价值常常不只看“收单成功率”，而要看资金管理整体收益
- 在某些纯支付或极重型全渠道零售能力上，不一定比 `Adyen` 更强

### 在之前会话里的定位

如果你的问题不只是“怎么收钱”，还包括：

- 怎么收多币种
- 怎么换汇
- 怎么做全球资金管理

那它在之前讨论里就会比很多纯支付网关更值得看。

---

## 3.6 `dLocal`

### 当时为什么会推荐它

因为它在之前会话里一直被放在：

- 新兴市场本地支付覆盖

这个维度里。

### 更适合什么业务

- 拉美扩张
- 中东扩张
- 非洲扩张
- 某些亚洲新兴市场本地支付方式覆盖

### 强项

- 在新兴市场本地支付方式覆盖上更有价值
- 可以补传统欧美主 PSP 的地区性短板

### 局限

- 如果你的主要市场是北美 / 欧洲成熟卡支付市场，它通常不是第一主选
- 很多时候更适合作为补充，而不是唯一全球主平台

### 在之前会话里的定位

它更像：

- 区域补强型平台

而不是：

- 所有国际业务的唯一默认主平台

## 4. 为什么还要补看 `PayPal / Braintree`

虽然你上次点名主要是：

- `Stripe`
- `Paddle`
- `Adyen`
- `Checkout.com`
- `Airwallex`
- `dLocal`

但之前会话里，`PayPal / Braintree` 也被反复放在“国际支付方案补充项”里。

### 它更像什么

- 不是总是承担整套复杂国际支付主链路
- 更像：
  - 钱包支付补充
  - 欧美用户偏好的补充入口

### 什么时候很值得加

- 你的用户主要在欧美
- 消费者对 PayPal 认知强
- 你想提升钱包支付转化

### 什么时候不适合作为唯一核心

- 复杂平台分账
- 很重的全球统一支付架构
- 需要订阅 + 税务托管 + 多币种资金管理一起打包

这时候它通常不如主 PSP + PayPal 补充的结构更合理。

## 5. 如果按“当前项目是否适合”来排优先级

这里要特别注意：

你当前这个 `new-api` 项目，和传统国际电商站点不完全一样。

## 5.1 如果你当前主要做国内充值

那国际平台这组里，真正最值得留意的通常只有：

- `Stripe`
- `Paddle`

原因是：

- 它们更容易和“开发者产品 / SaaS / API 平台”这个项目气质对上

而下面这些：

- `Adyen`
- `Checkout.com`
- `Airwallex`
- `dLocal`

更多属于：

- 规模上来以后再认真评估的第二层候选

## 5.2 如果你后面要做海外充值 / 海外订阅

可以这样看：

### 海外充值主链路

- 第一优先：`Stripe`
- 第二优先：`Adyen` / `Checkout.com`

### 海外订阅主链路

- 如果更重控制权：`Stripe Billing`
- 如果更重少折腾税务与销售主体责任：`Paddle`

### 海外钱包补充

- `PayPal / Braintree`

### 新兴市场补充

- `dLocal`

### 多币种资金流强化

- `Airwallex`

## 6. 按场景给你一份更直接的推荐表

## 6.1 我是出海 SaaS / 开发者平台

建议顺序：

1. `Stripe`
2. `Paddle`
3. `Adyen`

说明：

- `Stripe` 更适合自己掌控支付链路
- `Paddle` 更适合少管一部分税务和合规
- `Adyen` 更适合规模更大以后再评估

## 6.2 我是软件订阅 / 年付月付套餐

建议顺序：

1. `Paddle`
2. `Stripe Billing`
3. `Adyen`

## 6.3 我是跨境电商 / 中大型国际线上交易

建议顺序：

1. `Checkout.com`
2. `Stripe`
3. `Adyen`

## 6.4 我是大型全球企业 / 多国家品牌

建议顺序：

1. `Adyen`
2. `Checkout.com`
3. `Stripe`

## 6.5 我主要在拉美 / 中东 / 非洲

建议顺序：

1. `dLocal`
2. `Stripe`
3. `Airwallex`

## 6.6 我最在意多币种账户与跨境资金管理

建议顺序：

1. `Airwallex`
2. `Stripe`
3. `Adyen`

## 8. 如果只给你一句选型建议

如果你想让我把这份文档再压成一句话，那就是：

> 海外主链路优先看 `Stripe`，订阅和税务托管优先看 `Paddle`，企业级全球收单看 `Adyen` / `Checkout.com`，多币种资金流看 `Airwallex`，新兴市场看 `dLocal`，欧美钱包转化再补 `PayPal / Braintree`。
